## 🎨 Animation Details:

### Counter Animation:
- Duration: 2 seconds
- Easing: easeOutQuart
- Trigger: 50% in viewport
- Direction: 0 → target

### Skill Bars:
- Duration: 1.5 seconds
- Easing: cubic-bezier(0.4, 0, 0.2, 1)
- Trigger: 30% in viewport
- Direction: 0% → target%

### Image Zoom:
- Duration: 0.4 seconds
- Easing: cubic-bezier(0.4, 0, 0.2, 1)
- Trigger: hover
- Scale: 1 → 1.05

### Typing (ready, not active):
- Cursor blink: 0.7s infinite
- Character speed: configurable in JS
- Pause at end: configurable
