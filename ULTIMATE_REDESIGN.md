**Fonts:**
```
Primary:   Inter (UI, body, everything)
Accent:    Space Mono (technical details, code, specs)

```

**Scale:**
```
Hero:     96px / 900 weight  (HUGE name)
H1:       72px / 800 weight  (Page titles)
H2:       48px / 700 weight  (Section headings)
H3:       32px / 600 weight  (Card titles)

Body:     18px / 400 weight  (Readable)
Caption:  14px / 400 weight  (Meta info)

```

**Why This Works:**
- HUGE headlines create impact
- Clear hierarchy through size
- Readable body text
- Monospace for technical feel
- One font family = cohesive

### **Bento Grid System**

**Layout Logic:**
```
Grid: 12 columns
Gap: 24px
Breakpoints:
  - Desktop: 3-4 columns
  - Tablet: 2 columns
  - Mobile: 1 column (stacked)

Sizes:
  - Large card: 8 columns (featured)
  - Medium card: 6 columns (standard)
  - Small card: 4 columns (compact)
```

**Card Design:**
```css
Background: White (light) / #1A1A1A (dark)
Border: None
Shadow: 0 2px 8px rgba(0,0,0,0.04) (subtle)
Radius: 16px (modern)
Padding: 32px
Image: Full width, 240px height, rounded corners
Hover:
  - Lift 8px
  - Shadow: 0 12px 24px rgba(0,0,0,0.12)
  - Image: Scale 1.02x
  - Duration: 300ms ease-out
```

---

### **Button System**

```
Primary (Blue):
  - Background: #1E40AF
  - Text: White
  - Height: 56px
  - Padding: 0 32px
  - Radius: 8px
  - Hover: Darken 10%, lift 2px
  - Font: 16px / 600 weight

Secondary (Ghost):
  - Background: Transparent
  - Border: 2px solid #1E40AF
  - Text: #1E40AF
  - Rest same as primary

Icon Buttons:
  - Size: 48px × 48px
  - Background: #F5F5F5 (light) / #2A2A2A (dark)
  - Icon: 20px
  - Radius: 12px
```

---

### **Animation System** (Subtle & Smooth)

**Principles:**
- Only animate on user action or scroll
- 60fps (use transforms, not position)
- Easing: cubic-bezier(0.4, 0, 0.2, 1)
- Duration: 300ms standard, 500ms slow

**Animations:**

1. **Page Load:**
   - Hero fades in (400ms delay)
   - Nav slides down (200ms)
   - Content fades up staggered (100ms each)

2. **Scroll:**
   - Elements fade up as they enter viewport
   - Threshold: 20% visible
   - Once only (no repeat)

3. **Hover:**
   - Cards lift + shadow
   - Images scale 1.02x
   - Buttons lift 2px
   - Links underline slides in

4. **Click:**
   - Ripple effect on buttons
   - Page transitions (fade 200ms)

**No Animations:**
- No auto-playing anything
- No parallax (overdone)
- No typing effect (keep it simple)
- No percentage counters (removed)

## 📱 MOBILE-FIRST APPROACH

**Philosophy:**
- Design for mobile first
- Scale up to desktop
- Touch-friendly (48px minimum)
- Thumb-reachable nav
- No hover states (use tap)

**Breakpoints:**
```
Mobile:  < 768px  (1 column)
Tablet:  768-1024px (2 columns)
Desktop: > 1024px (3-4 columns)
```

**Mobile Optimizations:**
- Hamburger menu (smooth slide-in)
- Larger touch targets
- Reduced padding (16px sides)
- Stacked bento grid
- Simplified nav (3 items max visible)
- No hover effects (unnecessary)
